# Always Pinned

![Platform](https://img.shields.io/badge/platform-Chrome-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Manifest](https://img.shields.io/badge/manifest-v3-orange)

全タブを強制ピン留めし続ける Chrome 拡張機能です。新しいタブは開いた瞬間にピン留めされ、手動で解除しても即座に再固定されます。ウィンドウごとに個別設定も可能です。

[English README](README.md)

---

## 機能

- **全タブ強制ピン留め** — 開いているすべてのタブを一括でピン留め
- **新規タブ自動ピン** — タブを開いた瞬間にピン留め
- **ピン解除を強制再固定** — 手動でピンを外しても即座に戻す
- **ウィンドウ単位の制御** — Chrome ウィンドウごとに個別に ON/OFF
- **ON/OFF 切替** — ポップアップからいつでも一時停止可能

### 類似拡張機能との比較

| 拡張機能 | 全タブ一括 | 新規タブ自動 | ピン解除を再固定 | ウィンドウ単位 | ON/OFF |
|---|:---:|:---:|:---:|:---:|:---:|
| **Always Pinned（本拡張）** | ✅ | ✅ | ✅ | ✅ | ✅ |
| Pin Unpin All | ✅ | ❌ | ❌ | ❌ | ❌ |
| Tab Pinner | ✅ | ✅（URL指定） | ❌ | ❌ | ❌ |
| Always Pin | ❌ | ✅（URL指定） | ❌ | ❌ | ❌ |

## インストール

> Chrome Web Store への公開は準備中です。

### ローカルで読み込む（デベロッパーモード）

1. このリポジトリをダウンロードまたはクローン
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON にする
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、リポジトリのフォルダを選択
5. ツールバーに 📌 アイコンが表示されます

---

## 使い方

ツールバーの 📌 アイコンをクリックしてポップアップを開きます。

| 操作 | 説明 |
|---|---|
| **このウィンドウ** トグル | 現在のウィンドウだけピン留めを ON/OFF |
| **▶ このウィンドウを全ピン留め** | 現在のウィンドウの未ピンタブをすぐにピン留め |
| **✕ このウィンドウを全解除** | 現在のウィンドウの全ピンを解除 |
| **既定値** トグル（下部） | 個別設定のないウィンドウに適用されるデフォルト |
| **× リセット** リンク | ウィンドウの個別設定を削除して既定値に戻す |

> **注意:** ウィンドウ単位の設定はブラウザ再起動時にリセットされます（Chrome の仕様でウィンドウ ID が変わるため）。

---

## 使用権限

| 権限 | 理由 |
|---|---|
| `tabs` | タブの状態の読み取りとピン留め状態の変更 |
| `storage` | ON/OFF 設定の保存 |

外部への通信は一切ありません。データはブラウザ外に出ません。
