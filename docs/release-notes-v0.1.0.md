# Always Pinned v0.1.0

Initial public release.

## Features

- Pin all tabs in the current window
- Automatically pin new tabs
- Re-pin manually unpinned tabs by default
- Enable or disable pinning per Chrome window
- Global default setting
- Options to exclude new tab pages and respect manual unpins

## Package

- Chrome Web Store package: `always-pinned-v0.1.0-webstore.zip`
