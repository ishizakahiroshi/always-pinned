# Always Pinned v0.1.1 を公開しました

Chromeのタブを自動でピン留めし続ける拡張機能「Always Pinned」の `v0.1.1` を公開しました。
Chrome Web Store には現在申請中です。

## 今回の更新

- 紹介動画を追加
- ポップアップUIを日本語/英語に対応
- バッジ表示を調整（OFFのときだけ表示）
- README（英語/日本語）を更新

## こんな使い方を想定しています

- 作業タブを常に左側へ固定しておきたい
- タブを開くたびに手動でピン留めしたくない
- ウィンドウごとにON/OFFを切り替えたい
