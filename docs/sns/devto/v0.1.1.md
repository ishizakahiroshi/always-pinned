I released **Always Pinned v0.1.1**, a Chrome extension that keeps tabs pinned automatically.
The extension is currently submitted to the Chrome Web Store and under review.

## What it does

- Pins newly opened tabs automatically
- Re-pins manually unpinned tabs (unless you opt out)
- Supports per-window ON/OFF behavior

## What's new in v0.1.1

- Added a promo video
- Added popup localization (English/Japanese based on browser language)
- Updated badge behavior (`OFF` only when disabled)
- Updated English/Japanese README sections
