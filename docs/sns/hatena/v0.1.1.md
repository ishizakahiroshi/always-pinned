# Always Pinned v0.1.1 をリリースしました（Chrome拡張）

Chromeタブを自動でピン留めする拡張 `Always Pinned` の `v0.1.1` を公開しました。
Chrome Web Store には現在申請中です。

## 変更点

- 紹介動画を追加
- ポップアップUIの日本語/英語ローカライズ
- バッジ表示を調整（無効時のみ `OFF` 表示）
- README（英語/日本語）を調整
