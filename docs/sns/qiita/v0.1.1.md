# Chromeのタブを「常にピン留め」する拡張を v0.1.1 に更新しました

`Always Pinned` の `v0.1.1` をリリースしました。  
Chrome で「新規タブが増えても、手動解除しても、必要ならすぐ再ピン留め」にしたい人向けの拡張です。
Chrome Web Store には現在申請中です。

- Release: https://github.com/ishizakahiroshi/always-pinned/releases/tag/v0.1.1
- Repository: https://github.com/ishizakahiroshi/always-pinned
- Promo video: https://github.com/user-attachments/assets/b6619107-b977-49e8-82bd-612b725b2118

## v0.1.1 の変更点

### Added

- 紹介動画を追加
- ポップアップUIの日本語/英語ローカライズ（ブラウザ言語で自動切替）

### Changed

- バッジ表示を調整（有効時は非表示、無効時のみ `OFF`）
- ポップアップ文言を見直し
- README（英語/日本語）を更新

## 使い方（最短）

1. `chrome://extensions` を開く
2. デベロッパーモードを ON
3. このリポジトリを `Load unpacked` で読み込む

不具合や改善案は Issue で歓迎です。
