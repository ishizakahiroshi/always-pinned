# Chrome Web Store 掲載文案

## 拡張機能名

Always Pinned

## 短い説明

すべてのタブを自動でピン留めし、タブバーをコンパクトに保つ Chrome 拡張機能です。

## 詳細説明

Always Pinned は、開いているタブを自動的にピン留めして、Chrome のタブバーをコンパクトに保つための拡張機能です。

新しいタブは開いた直後にピン留めされ、手動でピンを外した場合も設定に応じて再度ピン留めできます。ウィンドウごとの ON/OFF に対応しているため、作業用ウィンドウだけ有効にする使い方もできます。

主な機能:

- 開いているタブをまとめてピン留め
- 新規タブを自動でピン留め
- 手動で外したピンを再固定
- Chrome ウィンドウごとの ON/OFF
- 既定値設定と一時停止
- 新規タブ除外と手動解除尊重のオプション
- ポップアップでの状態表示・プリセット・タブ行からの例外操作
- キーボードショートカットで現在ウィンドウのピン留め切替
- タブの右クリックから「再ピンしない / 再ピン対象に戻す」

プライバシー:

- 外部サーバーへの通信は行いません
- 個人情報を収集しません
- 閲覧履歴やページ内容を送信しません
- 設定は Chrome のローカルストレージに保存されます

使用権限:

- tabs: タブのピン留め状態を確認し、ピン留め状態を変更するために使用します
- storage: 拡張機能の ON/OFF 設定を保存するために使用します
- contextMenus: タブの右クリックメニューから例外登録・復帰を行うために使用します
