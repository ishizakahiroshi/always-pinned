# Chrome Web Store Listing Draft

## Name

Always Pinned

## Short Description

Automatically keeps tabs pinned so your Chrome tab bar stays compact.

## Detailed Description

Always Pinned is a Chrome extension that keeps your tabs pinned automatically, helping your tab bar stay compact and easier to scan.

New tabs are pinned as soon as they open. If a tab is manually unpinned, the extension can pin it again depending on your settings. You can also enable or disable the behavior per Chrome window, so it can stay active only where you need it.

Features:

- Pin all open tabs at once
- Automatically pin new tabs
- Re-pin tabs after manual unpinning
- Enable or disable per Chrome window
- Global default setting and quick pause
- Options for excluding new tab pages and respecting manual unpins
- Popup status hero, presets, and per-tab keep-unpinned actions
- Keyboard shortcut to toggle pinning for the current window
- Tab context menu: keep unpinned / allow re-pin again

Privacy:

- No external network requests
- No personal data collection
- No browsing history or page content is transmitted
- Settings are stored locally in Chrome storage

Permissions:

- tabs: Used to read and update tab pinned status
- storage: Used to save extension settings
- contextMenus: Used for tab right-click actions to keep a tab unpinned or restore re-pin
