# プライバシーポリシー

最終更新日: 2026-05-10

Always Pinned は、ユーザーの個人情報を収集、保存、販売、共有しません。

## 収集する情報

この拡張機能は、個人情報、閲覧履歴、ページ本文、入力内容、Cookie、認証情報を収集しません。

## 外部通信

この拡張機能は、外部サーバーへの通信を行いません。

## ローカルに保存する情報

拡張機能の設定を Chrome のローカルストレージに保存します。保存される情報は、ON/OFF 設定、ウィンドウ単位の設定、手動解除を尊重するための一時的なタブ ID などです。

これらの情報はユーザーのブラウザ内に保存され、外部に送信されません。

## 使用する権限

- tabs: タブのピン留め状態を確認し、必要に応じてピン留め状態を変更するために使用します。
- storage: 拡張機能の設定を保存するために使用します。

## 変更

このポリシーを変更する場合は、この文書の更新によって通知します。
