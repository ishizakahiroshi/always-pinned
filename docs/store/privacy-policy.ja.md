# プライバシーポリシー

最終更新日: 2026-08-25

Always Pinned は、ユーザーの個人情報を収集、保存、販売、共有しません。

## 収集する情報

この拡張機能は、個人情報、閲覧履歴、ページ本文、入力内容、Cookie、認証情報を収集しません。

## 外部通信

拡張機能自身が外部サーバーへの通信を行うことはありません。1 点だけ例外があります。ポップアップを開いている間、タブ一覧に表示する favicon 画像を Chrome が各ウェブサイトから直接読み込みます（通常のブラウザによる画像取得で、リファラーは送信しません）。それ以外の外部通信はなく、拡張機能がデータを送信することもありません。

## ローカルに保存する情報

拡張機能の設定を、ユーザーのデバイス上の Chrome ストレージに保存します。永続設定（ON/OFF、新規タブ除外、手動解除尊重）は `chrome.storage.local` に保存されます。ウィンドウ単位の一時設定と、手動解除を尊重するための一時的なタブ ID は `chrome.storage.session`（メモリ上・ブラウザ再起動時に消去）に保存されます。

これらの情報はユーザーのブラウザ内に保存され、拡張機能によって外部に送信されません。

## 使用する権限

- tabs: タブのピン留め状態を確認し、必要に応じてピン留め状態を変更するために使用します。
- storage: 拡張機能の設定を保存するために使用します。
- contextMenus: タブの右クリックメニューから「再ピンしない」「再ピン対象に戻す」を提供するために使用します。

## 変更

このポリシーを変更する場合は、この文書の更新によって通知します。
