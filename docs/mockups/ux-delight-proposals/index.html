対象: Always Pinned 草案 v0.1.2 起点 · 2026-07-10

ユーザーが喜ぶ機能・UX 改善提案

直近リポジトリに独立した UI 提案ドキュメントは無かったため、現行 popup（v0.1.2）と直近監査・改善 plan の文脈から、利用者が「分かりやすい・迷わない・一手で済む」と感じる改善案を wireframe 付きで起こした。実装確定ではない。

TL;DR — コアの「全タブ強制ピン」はそのまま。変えたいのは (1) 状態が一目で分かる、(2) 例外操作がタブ行からできる、(3) 設定の意味が日本語でも腹落ちする、(4) 手を離さずキーボードで止められる。の 4 点。

なぜ今 UX か

  • 直近作業はバグ・セキュリティ監査（F1–F6）と unpin フロー修正が中心で、品質は高い。見た目・導線の提案は未着手。
  • 現状 popup は機能が揃っているが、ラベルが短く「手動解除を尊重」など初見で意味が取りにくい。
  • タブ一覧は close のみ。ピン／解除の個別操作が無く、「この 1 枚だけ外したい」時に Chrome 標準操作へ戻る。
  • ウィンドウ個別設定と手動解除リストは再起動で消える（仕様）。ユーザーが驚くポイントなので UI で先回りして伝える余地がある。

やらないこと（スコープ外）

  • UI の全面ブランド刷新（色・フォントを Chrome Material から大きく外す）— 拡張 popup は OS/Chrome に寄せた方が違和感が少ない。
  • クラウド同期・アカウント・外部 API — 現状「通信なし」が売り。
  • ドメイン許可リストだけの別モードへの作り直し — コア価値（全タブ強制）と衝突しやすい。例外は「手動解除リスト」路線で足す。
  • Side Panel 常駐 — 需要はあるが権限・幅のコストが大きい。第二波以降。
